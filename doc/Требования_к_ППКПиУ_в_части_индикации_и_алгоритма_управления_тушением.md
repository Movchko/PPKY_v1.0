Требования к ППКПиУ
в части индикации и алгоритма управления тушением
1. Область применения
Настоящие требования устанавливают функциональные требования к прибору приемноконтрольному пожарному и управления (ППКПиУ), совмещающему в одном изделии
функции ППКП и ППУ, в части:
1.1 звуковой и световой индикации;
1.2 алгоритма управления исполнительными устройствами систем противопожарной
защиты (далее — управление тушением).
2. Термины состояний
2.1 ВНИМАНИЕ — состояние предварительной пожарной тревоги, формируемое при
поступлении признаков возможного пожара, недостаточных для подтвержденного
состояния ПОЖАР.
2.2 ПОЖАР 1 — состояние подтвержденной пожарной тревоги первого уровня, формируемое по алгоритму принятия решения ППКПиУ.
2.3 ПОЖАР 2 — состояние подтвержденной пожарной тревоги повышенного приоритета (второго уровня), используемое для запуска дальнейших действий согласно
алгоритму ППКПиУ.
2.4 ПОЖАР — обобщенное пожарное состояние, включающее режимы ВНИМАНИЕ,
ПОЖАР 1 и ПОЖАР 2.
2.5 НЕИСПРАВНОСТЬ — состояние, указывающее на отказ, повреждение или недопустимое отклонение параметров линий связи, питания или внутренних узлов ППКПиУ.
2.6 ПУСК — состояние выдачи ППКПиУ управляющего сигнала на включение исполнительных устройств системы противопожарной защиты по заданному направлению.
2.7 ОСТАНОВ ПУСКА — состояние ручного запрета (прерывания) выполнения пуска
по соответствующему направлению.
2.8 АВТОМАТИКА ОТКЛЮЧЕНА — состояние, при котором автоматический режим управления по одному или нескольким направлениям отключен (перевод в
ручной режим и/или блокировку).
2.9 ОТКЛЮЧЕНИЕ — состояние временного вывода из работы отдельных входов,
функций, шлейфов, зон, адресов или линий связи для проведения регламентных
и иных работ.
2.10 ТЕСТ — состояние выполнения процедур проверки работоспособности элементов
индикации, сигнализации, узлов и функций ППКПиУ.

3. Требования к звуковой и световой индикации
3.1 ППКПиУ должен обеспечивать отображение информации о режимах и событиях
средствами световой индикации и встроенной звуковой сигнализации.
3.2 ППКПиУ должен обеспечивать цветовую идентификацию индикации:
3.2.1 красный цвет — для состояний ПОЖАР и ПУСК;
3.2.2 желтый цвет — для состояний НЕИСПРАВНОСТЬ, ОТКЛЮЧЕНИЕ, АВТОМАТИКА ОТКЛЮЧЕНА, ОСТАНОВ ПУСКА, ТЕСТ, ЗВУК ОТКЛЮЧЕН;
3.2.3 зеленый цвет — для состояния ПИТАНИЕ и индикации штатного режима.
3.3 ППКПиУ должен иметь обобщенные световые индикаторы не менее: ПОЖАР,
НЕИСПРАВНОСТЬ, ПИТАНИЕ.
3.4 Для функций управления тушением ППКПиУ должен обеспечивать индикацию
состояний ПУСК, ОСТАНОВ ПУСКА и АВТОМАТИКА ОТКЛЮЧЕНА с расшифровкой по направлениям.
3.5 При использовании одного обобщенного индикатора для отображения состояний
ВНИМАНИЕ, ПОЖАР 1 и ПОЖАР 2 режимы индикации должны обеспечиваться следующим образом:
3.5.1 для состояния ВНИМАНИЕ — прерывистое свечение (мигание) с частотой
от 0,2 до 0,5 Гц;
3.5.2 для состояния ПОЖАР 1 — прерывистое свечение (мигание) с частотой от
1,0 до 2,0 Гц;
3.5.3 для состояния ПОЖАР 2 — непрерывное свечение.
3.6 Световая индикация состояния ПУСК должна выполняться непрерывным свечением.
3.7 Световая индикация состояния АВТОМАТИКА ОТКЛЮЧЕНА должна выполняться непрерывным свечением.
3.8 При использовании многоцветного индикатора для совместного отображения состояний НЕИСПРАВНОСТЬ и ОТКЛЮЧЕНИЕ индикация должна выполняться
следующим образом: для состояния НЕИСПРАВНОСТЬ — прерывистым свечением (миганием) с частотой от 0,2 до 0,5 Гц, для состояния ОТКЛЮЧЕНИЕ —
непрерывным свечением.
3.9 Световая индикация состояния ОСТАНОВ ПУСКА должна отображать факт активного останова пуска по соответствующему направлению.
3.10 ППКПиУ должен обеспечивать расшифровку направления события (шлейф, зона, линия связи, адрес устройства, выход управления) посредством единичных
индикаторов по направлениям и/или текстового средства отображения.
3.11 Для адресного исполнения ППКПиУ должен обеспечивать текстовый вывод с
отображением адреса источника события, типа события и последовательности
(очередности) поступления событий.

3.12 ППКПиУ должен обеспечивать звуковую сигнализацию для событий ПОЖАР
(включая ВНИМАНИЕ, ПОЖАР 1, ПОЖАР 2), ПУСК и НЕИСПРАВНОСТЬ.
3.13 Уровень звукового давления на расстоянии 1 м от ППКПиУ должен быть не менее:
3.13.1 60 дБ(А) — для сигналов ПОЖАР/ВНИМАНИЕ и ПУСК;
3.13.2 50 дБ(А) — для сигнала НЕИСПРАВНОСТЬ.
3.14 Звуковые сигналы состояний ПОЖАР, ПУСК и НЕИСПРАВНОСТЬ должны
быть различимы по параметрам сигнала (частота, модуляция, структура).
3.15 При одновременной регистрации нескольких событий ППКПиУ должен формировать световую и звуковую индикацию по приоритету: ПУСК → ПОЖАР →
НЕИСПРАВНОСТЬ → прочие события.
3.16 Автоматическое отключение световой и звуковой индикации состояния ПОЖАР
не допускается.
3.17 ППКПиУ должен обеспечивать ручное отключение встроенной звуковой сигнализации при сохранении световой индикации и включении индикации ЗВУК ОТКЛЮЧЕН.
3.18 Отключение встроенной звуковой сигнализации не должно оказывать влияния на
прием новых извещений и работу внешних средств оповещения.
3.19 При поступлении нового события после ручного отключения звука звуковая сигнализация должна возобновляться автоматически.
3.20 ППКПиУ должен иметь режим тестирования элементов световой индикации, текстового отображения и звуковой сигнализации с автоматическим возвратом в
предшествующий режим работы.
3.21 Длительность тестирования индикации и звуковой сигнализации должна составлять не более 20 с.
4. Требования к алгоритму управления тушением
4.1 ППКПиУ должен реализовывать функции управления исполнительными устройствами систем противопожарной защиты в автоматическом и ручном режимах.
4.2 ППКПиУ должен обеспечивать прием электрических сигналов от технических
средств, формирующих стартовый сигнал запуска управления тушением.
4.3 ППКПиУ должен обеспечивать прием сигналов от устройств, регистрирующих
срабатывание систем противопожарной защиты, если такие устройства предусмотрены алгоритмом системы.
4.4 ППКПиУ должен осуществлять автоматический контроль исправности линий связи:
4.4.1 для проводных линий — на обрыв и короткое замыкание;
4.4.2 для радиоканальных, оптоволоконных и цифровых линий — на пропадание
связи.
3
4.5 Время перехода ППКПиУ в состояние НЕИСПРАВНОСТЬ с момента возникновения неисправности линии связи должно быть не более 100 с, для радиоканальных
линий — не более 300 с.
4.6 ППКПиУ должен обеспечивать пуск исполнительных устройств в автоматическом
режиме в соответствии с запрограммированным алгоритмом по каждому направлению.
4.7 ППКПиУ должен обеспечивать ручной пуск исполнительных устройств раздельно
по каждому направлению:
4.7.1 от органов управления ППКПиУ;
4.7.2 от устройства дистанционного пуска.
4.8 В ППКПиУ должна быть предусмотрена возможность использования обоих способов ручного пуска по каждому направлению.
4.9 ППКПиУ должен обеспечивать для каждого направления управления режимы:
4.9.1 автоматический;
4.9.2 ручной;
4.9.3 блокировка пуска (отключение функции управления).
4.10 ППКПиУ должен обеспечивать установку регулируемой задержки пуска исполнительных устройств после получения стартового сигнала:
4.10.1 не менее 30 с;
4.10.2 с шагом настройки не более 10 с;
4.10.3 независимо для каждого направления.
4.11 В режиме задержки пуска ППКПиУ должен обеспечивать:
4.11.1 приостановку отсчета времени задержки;
4.11.2 возобновление отсчета;
4.11.3 досрочный принудительный пуск;
4.11.4 отмену пуска.
4.12 Время реакции ППКПиУ на стартовый сигнал запуска управления тушением не
должно превышать 3 с.
4.13 ППКПиУ должен иметь не менее одного обобщенного дискретного выхода ПУСК
и одного обобщенного дискретного выхода НЕИСПРАВНОСТЬ для передачи соответствующих сигналов во внешние цепи.
4.14 Время активации выходов ПУСК и НЕИСПРАВНОСТЬ после регистрации события не должно превышать 10 с.
4.15 ППКПиУ не должен формировать стартовый сигнал управления тушением в режиме ВНИМАНИЕ.
4.16 При наличии задержки пуска ППКПиУ должен обеспечивать индикацию отсчета
времени до пуска по соответствующему направлению.
4
4.17 ППКПиУ должен обеспечивать индикацию режима АВТОМАТИКА ОТКЛЮЧЕНА при переводе хотя бы одного направления в ручной режим или режим
блокировки пуска.
5. Контролепригодность требований
5.1 Требования настоящего документа должны быть проверяемыми при функциональных испытаниях ППКПиУ с имитацией входных событий и контролем выходных сигналов, индикации и временных параметров.
5.2 Приемка выполнения требований должна проводиться по протоколам испытаний
с фиксацией:
5.2.1 соответствия логики приоритетов;
5.2.2 правильности индикации состояний и направлений;
5.2.3 соблюдения ограничений по времени реакции и активации выходов;
5.2.4 корректности реализации режимов пуска, останова, блокировки и задержки.
